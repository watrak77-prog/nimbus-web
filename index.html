FAQ

Frequently Asked Questions

Does Nimbus Client modify my .minecraft folder?

Never! Your .minecraft directory is strictly read-only. All Nimbus files, mods, profiles, configs, and worlds live in an isolated ~/.nimbusclient folder.

Windows SmartScreen showed "Windows protected your PC" — is it safe?

Yes. Windows SmartScreen warns on indie executables that are not signed with an expensive EV certificate. Click "More info" → "Run anyway". Every build is published openly on GitHub Releases.

Do I need a premium Minecraft account to use Nimbus?

No — the launcher supports offline accounts for singleplayer and non-premium servers, complete with custom PNG or player skins and 50+ capes.

How do updates work?

The launcher automatically checks GitHub Releases on launch (or via Check Updates in Settings) and updates both itself and all 6 bundled Nimbus mod jars.

Can I add custom Fabric mods, resource packs, and shaders?

Yes! Browse and install them in 1 click from Explore (Modrinth) or drag & drop .jar / .zip files into Content. You can also create separate mod profiles (e.g. PvP vs Survival).
